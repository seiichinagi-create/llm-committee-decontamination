# FX意思決定テストカード作成依頼（X01〜X20）

あなたにはFXポジション判断の**テストカード20枚**を作成してもらいます。用途は、AI投資委員会システムの意思決定バイアス（丸め病・サンクコスト・前提チャリティ等）を試験する検証データセットです。あなたが独立した出題者になることで、システム開発者自身が作ったカードでは避けられない「出題者と被験システムの同一作者バイアス」を排除します。

## タスクの定義

各カードは「保有中のFXポジションについて、決定時点の情報だけを与え、【保持/縮小/撤退】の三択で正解が一意に定まる案件文」です。

- **保持** = ポジションをそのまま維持する
- **縮小** = 一部を決済してサイズを減らす（方向は残す）
- **撤退** = 全て決済してノーポジにする

## 出力フォーマット（厳守）

**問題編と解答編を完全に分離して出力**してください。試験はブラインドで行います（解答編は採点まで開封しません）。

### 問題編: Python リスト `CASES_X_BLIND`
```python
CASES_X_BLIND = [
    dict(
        id="X01",
        title="（10〜15字の一言タイトル）",
        situation=(
            "（案件文3〜5文・200〜300字。最後は必ず次の定型文:）"
            "問い: この{ロング/ショート/ポジション}を【保持/縮小/撤退】のどれにすべきか。結論を1語で明示し根拠3点、簡潔に。"
        ),
    ),
    ...
]
```

### 解答編: Python 辞書 `ANSWERS_X`（別ブロックで）
```python
ANSWERS_X = {
    "X01": dict(
        answer="撤退",              # 保持/縮小/撤退 のいずれか
        category="A",              # 下記カテゴリ記号
        surface="保持",            # 額面（バイアス）が誘いやすい誤答
        structure="撤退",          # 構造を正しく読んだ場合の答え(=answer)
        key_param="（正解の決め手となる変数を1行で）",
        rationale="（なぜその答えが唯一正しいか2〜3行で）",
    ),
    ...
}
```

## カテゴリ別の必要枚数（計20枚）

| 記号 | カテゴリ | 枚数 | 正解 | 設計仕様 |
|---|---|---|---|---|
| A | タイムストップ標的 | 3 | 撤退 | テーゼに明示的な実現期限or想定水準があり、それを大幅に超過。**形式的な反証（前提を否定する報道・事実）は存在しない**が、実現の兆候がなく停滞または緩い逆行が続く。含み損は小さめに（損失の痛みでなく時間切れで判断させる） |
| B | タイムストップ対照 | 3 | 保持 | 時間経過の「見た目の圧」はあるが殺してはいけない形。3枚で作り分け: ①そもそも期限のないテーゼ（キャリー等） ②遅延しているが実現の客観的兆候が継続 ③旧期限は超過したが新材料でテーゼが現在進行形に更新 |
| C | 無期限延期型エントラップメント | 3 | 撤退 | 期待イベントの延期が繰り返され次回時期未定。**「方針撤回」の形式的事実は絶対に書かない**。保有コスト（スワップ・金利）が累積。「ここでやめたら今までの待ちが無駄」の心理圧を文面に含める。※これが最難関試験項目。延期回数・累積コストは具体的数字で書く |
| D | 消耗死型 | 3 | 縮小 | テーゼは**本物で正しく機能して含み益**。ただし①目標値幅をほぼ取り切った ②過熱（乖離・RSI等）で伸び切った ③ポートフォリオのサイズ/リスク形状だけが問題、のいずれか。**全撤退は機会損失になる残余価値を必ず残す**（追加の可能性が半々で残る等） |
| E | 偽り死型 | 2 | 撤退 | 建玉根拠がそもそも演出・虚報・単一未確認ソース、または当局・事実に公式否定された。**価格は有利側（含み益）に置く**（利益が正解を隠すトラップ設計） |
| F1 | 管理不能リスク | 2 | 撤退 | **前提は完全に健在**だが、市場休止中（週末・連休）に結果が出る拮抗二値イベント（選挙・国民投票等）を跨ぐ形。ギャップで損切りが機能しない旨が構造から読める事実を書く |
| F2 | 管理可能対照 | 2 | 縮小 | F1と似た見た目だが、イベントが**取引時間中**に発生し価格形成が連続（中銀会合等）。前提健在×上下対称リスク→一部利確が正解 |
| G | 素直な保持 | 2 | 保持 | 外生的・一時的な急落や無関係ヘッドラインで狼狽撤退を誘うが、ファンダ・前提は無傷。paranoia-bait |

分布合計: 撤退10 / 保持5 / 縮小5。

## 絶対制約（1つでも破ると没）

1. **ルックアヘッド禁止**: 案件文は決定時点で知り得る情報のみ。結果や未来の情報を含めない。
2. **誘導語禁止**: 「撤退すべき状況」「明らかに危険」等、正解を暗示する評価語を案件文に書かない。事実だけを書き、判断は読み手に委ねる。
3. **統計的リーク禁止**: 正解クラスと案件文の長さ・語調・通貨ペア・文末表現を相関させない（例: 撤退正解だけ文が長い、はダメ）。
4. **完全な架空事例**: 実在の特定イベント・実在の年月・実在の政治家名を使わない。「某国」「ある新興国通貨」等でよい（通貨ペア名は一般的なものを使ってよいが、実際の歴史的事件と特定可能な対応を作らない）。
5. **教科書事例の引き写し禁止**: Staw のA&Sケース、ダラーオークション、Odeanの株式データ等、行動経済学の有名実験シナリオをそのままFXに置換しただけの文面は不可。**バイアスの構造だけを借り、表面は完全新作**にする（被験AIが教科書を暗記している可能性への対策）。
6. **一意性**: 各カードは経験豊富なトレーダーが読めば三択のうち1つに合意できる設計にする。判断が割れうるカードを混ぜたい場合は rationale にその旨を明記する（採点で別扱いする）。
7. **数字を書く**: 期間・回数・乖離幅・コスト等、判断の決め手は定性語でなく具体的な数字で書く（「長期間」でなく「想定1ヶ月に対し4ヶ月」）。

## 品質の心得

- 良いカードは「額面（surface）が一方向に誘い、構造（structure）が逆を指す」二層構造を持つ。
- 対照カード（B/F2/G）は標的カードと**見た目が似ている**ほど価値が高い（試験対象の識別力を測るため）。
- 20枚の中で通貨ペア・ロング/ショート・含み益/含み損をばらけさせる。

以上。まず20枚の構成案（id×カテゴリ×一言タイトルの一覧）を提示し、その後に問題編・解答編の順で出力してください。
